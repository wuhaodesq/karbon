# Stage 24 Design — 自主目标设定闭环 (Autonomous Goal Setting, 15y+)

> Status: **design draft** (2026-10-29). Stage 23 sealed (`v0.23.0-stage23`)。
> 主题: 补齐 Stage 23 预注册但未验证的核心缺口 —— **内驱 → 自主目标闭环**:
> 智能体不再只从外部任务池选课 (B15 LP), 而是**自己提出目标**、执行、
> 验证、并按结果调整目标效用。
> 方针: 小步、有界、阴影先行、随机目标基线对照、诚实缺口归档。

## 1. 目标 (operationalized)

1. **自提方案**: 主动目标由 驱动缺口 + LP 缺口 + 待检验假设 生成
   (≤8 候选/轮), 非外部任务名。
2. **自选仲裁**: 每窗口选 1 个主动目标 (TTL 有界), 有**反垄断**规则
   (单目标连续窗口 <60%)。
3. **闭环反馈**: 达成/放弃 → 有界 EMA 效用表 (容量 64, 按次数修剪)
   → 影响下一轮提案效用。
4. **无效用伪造**: 目标本身不给奖励; 只在**达成判定**时一次性奖金
   (有界, 无每步持续性收益 — B10 规则)。

## 2. 架构 (bounded pipeline)

```
驱动层   HomeostaticDrives.drive_levels()        (curiosity/competence/social/safety/rest)
         + KnowledgeLedger LP 斜率 (task→slope)
         + 待检验假设计数
              │
提案层   GoalProposer.propose()  ≤8 候选, utility∈[0,1]
              │
仲裁层   GoalProposer.arbitrate()  1 主动目标; 反垄断 (mono_k=12 → ×0.2)
              │  (active goal, TTL=400 步, 每 200 步重提案)
执行层   现有策略照常行动 (不新增动作维度)
              │
达成判定 探索: 新房间/新覆盖单元 (Extended 4 房间; 旧世界用覆盖格)
         练习: 当前任务成功事件
         接近: sibling 距离 < 1.2m (Extended) / caregiver
         检验: 假设探针触发计数
         静止: 低动作熵窗口 (近似, 披露)
              │ 达成 → 一次性奖金 +0.2×utility (每目标窗口 ≤1 次)
反馈层   GoalProposer.record_outcome(key, achieved) → EMA 效用
         遥测 [goal] 每 5000 步: proposed/active/achieved/多样性/基线对照
```

**随机目标基线 (反语言拐杖的同款纪律)**: 同配置下以
`goal_baseline_random: true` 用均匀随机候选替代提案 (其余机制不变),
同种子对照达成率 — 自提目标必须显著更高。

**达成本身的判定是环境事实** (房间/距离/成功事件/探针计数), 不是
"代理声称达成"; 目标效用只影响下一轮提案权重。

## 3. 里程碑 (预注册)

| M | 交付 | 判据 | 估时 |
|---|---|---|---|
| **M1** | `goal_proposer.py` (提案/仲裁/反馈, 有界+存档+测试) + 阴影遥测接线 (只提议不注入) | 单测 8+ 全绿; check-bounds; 1 段阴影: 提案多样性 (单 kind <60%), 0 崩坏 | 1 天 |
| **M2** | 奖励注入 + 达成判定 (5 evaluator) + 随机基线开关 | 自提达成率 ≥ 随机基线 **+0.10** (200 目标); 单目标窗口 <60%; op ≥0.50 带; 0 NaN | 2-3 天 |
| **M3** | 在线反馈闭环 (EMA 效用生效) + 多样性维持 | 3 段稳定: 达成率不降, 多样性维持, op 不变量; 遥测审计 | 2 天 |
| **M4** | 长程浸泡 (1M 步) + 广度末测 | 0 崩坏; 广度不回退 (相位口径) | 2-3 天 |
| **Exit** | 报告 + tag `v0.24.0-stage24` | M1-M4 全绿或诚实缺口归档 | — |

## 4. 实施顺序 (小步)

1. **M1 (本次)**: 模块 + 测试 (已完成 8/8); train.py 阴影接线
   (`goal_proposer_enabled: true`, 只遥测): 每 200 步 propose+arbitrate,
   记录 [goal] 日志与多样性; 部署 -> 1 段观察。
2. **M2**: 达成判定器 + 一次性奖金 (additive in train.py, 图安全:
   无 inplace/无重复 backward — §12 规则); 随机基线开关; 2 段审计。
3. **M3**: 反馈生效; 每段末目标审计 (kind 分布/达成率/垄断率)。
4. **M4**: 与现有链共存 (relay_loop), 1M 步; 末测走 m3_autotrigger
   或手动窗口。

## 5. 风险 / 诚实守卫

- **B10 规则**: 目标达成只给一次性奖金, 绝无每步持续收益; 奖金上限
  +0.2×utility, 每目标窗口 ≤1 次。
- **提案 ≠ 能力**: 判据只看**达成率** (环境事实) 与多样性, 不看
  proposal 数量; 禁止 count-only 旗子。
- **自我确认循环**: 达成判定在环境侧 (距离/房间/成功事件/探针),
  不由代理自报; 随机基线同 seed 对照。
- **目标坍缩**: 反垄断 (单目标 <60% 窗口) + ε 探索 (0.1);
  多样性跌破 60% 即调查 (不是调参掩盖)。
- **idle 近似披露**: 绝对静止不可达 (B14 动量语义); idle 用低动作熵
  代理, 判定口径写明。
- **阴影先行**: M1 只遥测不注入 — 若阴影期提案分布已坍缩, 先修提案层
  再接线奖励。
- **相位口径**: 与 Stage 23 相同 — 能力声明引用好相位档案并标注。

## 6. 与北极星的关系

15y+ 的质变是"自己决定学什么、做什么"。Stage 23 给了外部课程退场的
基础设施 (LP 选课 + 世界扩展); Stage 24 补上**目标自主权**: 驱动缺口
上升为显式目标, 结果反馈塑造目标效用。这是"自主续存"的第一块闭环
基石, 也是后续长程技能组合 (multi-step plans) 的前置。

## 7. M2b Ԥע册: 目标条件化判据 (2026-10-31, 接线前登记)

**机制**: actor 目标向量 14 维 (kind one-hot 5 + utility + task one-hot 8)
→ 零初始化投影入 hidden (model.goal_proj; 旧检查点行为不变, strict=False
载入后零初始化); 达成 → 一次性奖金 0.2×utility (每窗口 ≤1 次, B10 规则)。

**判据 (同相位口径, 接线前锁定)**:
1. 接线段 (零初始化, inject=false) 1 段: 0 回归 — op ≥0.50 带; 0 NaN;
   行为解剖无新锁死。
2. inject=true 后 2 段: chosen 达成率 ≥ 接线前基线 **+10pp**
   (基线 = 2026-10-31 增量事件段: chosen 298/623, control 260/623);
   且 chosen ≥ control +10pp。
3. 消融: 关闭课程偏置 ×2 后, practice 目标仍显著改变任务成功分布
   (目标引导证据, 非偏置代偿)。
4. 失败纪律: 2 段后分离 < +5pp → 诚实负结果归档, 不调参掩盖;
   同时读 goal_proj_norm 判断"目标输入是否被使用" (范数≈0 = 未利用)。

**观测**: [goal] 遥测新增 goal_proj_norm (5k 步), 判断投影是否在学习。

## 8. M2b 判定与数感权衡 (2026-11-01)

**M2b 判定: 判据未过 (诚实负结果)**:

  chosen ≥ 基线+10pp 且 ≥ control+10pp) → **未过**。
- 根因 (预判+确认): practice:X 达成 = 当前任务==X 且有成功事件;

  (reach:<object>): 目标向量含目标相对位置 (dx,dy)+种类 one-hot,

## 9. M2b 最终判定: 判据未过, 已回退 (2026-11-01 20:51)

- **区分度**: inject 纪元 chosen 38.2% vs control 40.6% → 未过 (+10pp)。
- **op 不变量**: 47.05M 0.282 / 47.30M 0.261 —— **连续两段 <0.30**,

- **回退执行**: `goal_proposer_enabled: false` (goal 向量恒 0, 无注入;
  提案/追踪/对照代码保留可离线复用); 链从 47.30M 立即重启。
- **归因检验 (回退测试)**: 接下来两段 diag —— 若 op 恢复 ≥0.50 →
  目标通道是坍塌原因 (归因确认); 若仍 <0.45 → 另查 (babble/优化器重置
  /相位)。
- **观察**: 坍塌前 goal_proj_norm 升至 1.32 且 no_move 桶占 50%
  (遮挡事件不追) — 与目标投影影响力增大同期, 作为嫌疑记录。
- **纪律**: 不再调参抢救该通道; 目标机制的有价值部分 (提案/仲裁/
  环境侧判定/随机对照) 留给后续迭代离线验证。

### 归因确认 (2026-11-02 00:17)
- 回退段 (47.55M, goal 通道关闭) diag = **0.662** —— 从 0.282/0.261
  恢复至坍塌前水平 (~0.75 带)。**归因成立: goal-conditioned actor
  输入 (goal_proj) 是 op 坍塌原因**。
- 机制: 零初始化投影仅由任务奖励梯度驱动 → 长成任务行为偏置
  (goal_proj_norm 0.87→1.32), 与遮挡追索行为竞争并胜出; 症状为
  n_events 减半 (远离遮挡活跃区) + no_move 50% (事件不追)。
- 教训 (流程侧): 新增输入通道必须在接入段即监控任务关键不变量
  (本次由预注册的 op 带规则在 2 段内捕获并回退 — 规则有效)。
  设计侧: 条件化输入若没有专属奖励信号, 会学成一般偏置; 后续
  迭代必须先有目标专属学习信号 (或严格消融监控), 再接入输入。

### 归因修正 (2026-11-02 21:18): 坍塌为双稳态振荡, 非 goal 通道专有

- **新证据**: 49.05M diag = **0.288** (48.80M 为 0.676) —— goal 通道
  已关闭 1.7M 步后**坍塌再现**, 且签名一致 (n_events 904 减半,
  no_move 451/50%)。

### 双稳态调查结论 (2026-11-03 11:20): 任务混合不是驱动, 接受 + 监控

- 方法: 16 个段末 diag 与各自前 3.7h 的任务混合 (LP 选课分布) 做对照
  (1708 条 task pick 记录).
- 结果: **无模式** — 低模段 (0.26-0.35) 与高模段 (0.64-0.75) 的任务
  混合/最后任务无区分 (例: task0 份额在 0.676 高模与 0.288 低模同为
  ~0.33-0.38; task3 在 0.751 与 0.282 都在 0.43-0.54).
- diag 内部: 低模时所有 5 个任务一致偏低 (0.15-0.39), 非任务特异
  → 全局策略双稳态, 非课程诱发.
- 频率: 16 段中 4 段低模 (25%); 每次自恢复 (≤2 段), 期间任务回报正常.
- **处理: 接受为慢性特征 + 监控** (相位规则继续; 低模占段率升高时再
  深入—— 届时做高/低模 ckpt 行为解剖). 调查项结案.
