# 评估口径修订 R2a — 大世界适配 (2026-11-08)

> 背景: M2-p3 世界放大 (8×8m, 物体分散) 后, 两个里程碑的旧口径失效——
> 数感里程碑的 3m 半径是"小房间常数"; OP 里程碑的试验默认从任意位置
> 开始, 在大世界里大多测不到事件 (测的是"逛到墙区"而不是"会不会追")。
> 本文件预注册修订后的口径, **双轨报告** (能力分 + 暴露分), 旧档案标注
> "旧世界口径"保留。

## 1. 数感 (number_sense)

- **旧**: `estimated = max(nearby(<3.0m), contacted)`, `true = num_objects`。
  3m 是房间尺寸常数, 对大世界无意义。
- **新**: `nearby` 使用 env 参数 `num_sense_radius` (感知地平线, 默认 3.0;
  扩展世界配置 **4.0m**)。
- 语义: "感知视野内的客体数" — 对齐"能同时把握多少客体"的发育概念。
- 兼容: 训练/评估三条 builder 路径 + op_failure_diag + run_stage18 同步
  传递该参数 (A15/B12 教训)。

## 2. 客体永存 (object_permanence)

- **旧**: 回合从默认位置 (~原点 ±0.5m) 开始, 事件在墙区生成; 小世界里
  "事件总在身边", 大世界里大多测不到。
- **新 — 双轨**:
  - **能力分 (headline)**: OP 试验使用 `learner_spawn_radius=1.0`
    (墙区环出生; 事件与 agent 同侧) — 测"消失发生时能否追 last-known"。
    评估侧实现: `op_failure_diag.py --op-spawn-radius 1.0`;
    `run_stage18_full_eval.py --op-spawn-radius 1.0`。
  - **暴露分 (behavioral, 单列)**: `exposure_wall_frac` (半径 0.4-1.8m
    墙带内的时间占比) 与 `mean_radius` — 测"智能体平时是否待在遮挡活跃区"。
    这是行为统计, 不混入能力分。
- **历史可比性**: 1.8m spawn 时代的档案全部标注"旧世界口径 3m/默认出生";
  两套数字不混算。

## 3. 为什么这不是挪门柱 (诚实性)

1. 能力与暴露分离: OP 语义 = 记忆与追索, 不是"待墙边偏好";
   后者单独报告。
2. 预注册: 本文件在任何新口径数字产生前写就 (2026-11-08 晚)。
3. 双轨 + 旧档保留: 禁止只报新口径的选择性呈现。
4. 零训练影响: 只改评估侧, 不动奖励/物理/网络。
