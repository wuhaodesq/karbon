## 4. 诚实缺口 (不粉饰)

1. **M3b 执行器是脚本化贪心**（披露），非学习策略；语言→目标的**解析器
   为模板词表**（电池口径）。6 个 live 失败全为卡墙（无避障）。
2. **LLM 润色接受率低**：M3a 多数输出回退骨架 — 事实保真达标，**流畅度
   轴单列**（未在本阶段验收）。
3. **平衡相位 vs 字面判据**：M3 的 OP≥0.6 只在好相位档案满足；当前训练
   态 0.55 带（已决议接受）。
4. **num 感 1/3 过门**（好相位时代带）、ToM 0.68 仍低于金档 0.57-0.58
   （S20）记录未消。
5. **概念桥 movable 通道**整期未获 carry 经历（S22 记录未变）。
6. **服务器 repo 漂移**（Stage-12 老检出 + 散装部署）→ 全套测试门禁以
   本地仓库为准；服务器只跑目标测试。
7. M4 "1M 步浸泡" 以**连续血统**满足（17.4M 步），非独立浸泡实验；
   期间 op 曾入平衡带（已按决议处理）。
