# Stage 26 Design — 接地阅读 (Grounded Reading, 社会继承的第一步)

> Status: **design draft** (2026-11-04). 承 Stage 25 语言回路 (M-L1 通道已上线)
> 与北星路线 (`docs/path-to-northstar.md`) 的第四道门扩展。
> 问题: 人类通过语言继承他人经验 (阅读/听讲) 实现知识指数增长;
> 当前智能体只能从自己的经验学习。本阶段引入**接地阅读**: 文字必须先被
> 经验验证 (或挂在已接地概念上) 才能进入知识库, 再经巩固进入权重。

---

## 0. 为什么符合发育路线

- 人类阅读建立在 ① 多年感官经验 ② 母语习得 (词→指代) ③ 文字→经验映射之上;
  本设计完全对应: 文字断言必须与场景事实核对, 不可验证的断言**拒绝入库**
  (无根知识 = 项目明确排除)。
- 这不是"外挂 LLM 知识库": 冻结编码器只做接口 (无决策权), 知识进入
  语义层 (概念桥/符号库) 与权重层 (巩固训练), 路径与人类"情景→语义→
  突触"三层一致。
- 发育节奏: 儿童 6-8 岁从"看图说话"到"读简单句子", 词汇量靠
  **可验证的日常经验**扩张 — 与 R1-R3 的课程曲线同构。

## 1. 机制 (三层管道, 全有界)

```
文本断言 (模板/小语料/程序化生成, 例如 "the red box is behind the wall")
   │  R1 经验验证: 在场景/记忆/概念桥中核对 (真/假/不可验证)
   ▼  不可验证 → 拒绝 (记录拒绝率; 拒绝率过高 = 课程不匹配)
语义库 (概念桥/符号库; 容量声明: cloud_24g=10^5, home_64g=10^6 条)
   │  R2 入库: 去重/合并/泛化 (实例→类别), 带来源与验证记录
   ▼
权重巩固 (R3): 周期性对已验证事实做辅助训练 (概念 prover + 语言接口),
  让"会说"变成"会做/会用" (单份事实库, 不进检查点)
```

**存储**: 事实库独立有界 (单份); 事实大小 ~50-200B → 10^6 条 ≈ 50-500MB,
home_64g 余量内; 文本编码器冻结 (~0.3-0.6GB 磁盘, VRAM +0.25GB)。

## 2. 里程碑 (预注册)

| M | 交付 | 判据 | 估时 |
|---|---|---|---|
| **R1** | 文本→场景验证器 (拒绝无根断言) | 验证精度 ≥0.95 (人工核对 200 条); 拒绝机制有记录 | 2 天 |
| **R2** | 语义入库 (概念桥/符号库接入) | 每段摄入 ≥500 条已验证事实; 去重/合并生效; 库容量声明 + 修剪 | 2-3 天 |
| **R3** | 巩固闭环 (事实→权重) | held-out 事实的问答/推理准确率 ≥0.7; 巩固前后可测提升; op 不变量 | 3-4 天 |
| **R4** | 社会继承实验 (与自学习对照) | 相同壁钟时间内, 阅读组知识获取量 ≥ 纯自经验组 **3×**; 无退化 | 3-4 天 |
| **Exit** | 报告 + tag `v0.26.0-stage26` | R1-R4 全绿或诚实缺口归档 | — |

## 3. 硬件账 (A 档)

| 项 | 增量 | 结论 |
|---|---|---|
| 文本编码器 (冻结) | 磁盘 0.3-0.6GB, VRAM +0.25GB | 现有 12GB/100GB 余量内 |
| 文本语料 | ≈0 (程序化生成) | 不下载大语料 |
| 事实库 | RAM/磁盘 5-500MB (按容量声明) | home_64g 内 |
| 训练步时 | +20-50% (文本批次交错) | 本地可承受 |
| 检查点 | 不变 (事实存独立库) | 备份链不膨胀 |

## 4. 风险 / 诚实守卫

- **无根知识禁令**: 只有通过验证的事实可入库; 拒绝率、来源、验证时间全记录;
  任何"知识注入"断言必须可追溯到验证记录。
- **LLM 边界**: 编码器冻结, 只做接口; 禁止用生成模型概括文本后入库
  (那是知识外挂, 违反从零发育)。若将来引入文本编码, 只允许**冻结小模型**。
- **失败纪律**: R4 若阅读组优势 <1.5× → 诚实负结果 (社会继承在本架构下
  不成立), 归档并回退通道。
- **能力声明**: 阅读能力声明限于"验证过的知识范围"; 不声称通用阅读理解
  (那是 B 档, 需要语言规模化, 超出 home_64g)。
- **双稳态/op**: 与 Stage 25 同口径监控; 输入通道接入即监控。

## 5. 与北极星的关系

第四道门 (语言) 的规模化第一步: 从"能说/能听"到"能从文字学习"。
人类知识量的指数增长来自社会继承; 本阶段让智能体首次接上这条通道,
且保持"每条知识可验证、每步发育可追溯"的诚实框架。
