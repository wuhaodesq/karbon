  数据 bug 已修)。

### M2 — 概念级规则演绎 (电池通过)

- 有界统一器后向链 (变量绑定/规则/事实/深度/op 全封顶); 内置 R1 继承 /
  R2 超类抽象 / R3 蕴含组合。
- **电池**: 3 世界 540 期望属性 — full recall **1.000** / precision
  **1.000** (零伪推导); 实例级基线 (R1+R3) recall **0.400** — **+60pp**。
- 途中修复 (台账同源): var→var 别名完整解引用; 规则局部变量按规则重命名;
  答案解析为查询变量位绑定值。

### M3 — 关系迁移类比 (电池满分, 保守解读)

- A:B :: C:? = `emb(c) + (emb(b)-emb(a))` 最近邻; 关系无需标签; 有界 + ckpt。
- **电池**: 3 关系 × 90 held-out — top-1 **1.000** (随机 0.0056), 判据
  (+0.1) 大幅达成。**保守注**: 合成关系为干净线性偏移, 机制即标准向量算术。

### M4 — 训练集成 + 验证 (在线 3 天+)

- `concept_bridge.py`: 被动概念桥 — 真实世界物体→实例→类别/超类; 实际
  搬运 (carry>0.05) → movable 事实; 类别泛化 (≥2 成员) → prover 演绎
  (M2 规则) 供新实例继承; 有界 (实例 256 / 事实上限 / 每类桶盖) + ckpt
  持久化 (含 prover 事实)。train.py: 构造/episode 末 `feed_episode` 单调用/
  `[concept]` 5000 步遥测/存档恢复。
- **在线遥测 (2026-10-11 → 10-15)**: instances 8→16, categories 4→6,
  supers 3→4, 随后稳定; bridge 喂入失败 **0**; 无退化。
- **movable 通道休眠 (诚实记录)**: 策略整期未发生 carry>0.05 → 0 事实;
  通道在线但无经历输入。
- **G3 num_sense 复验** (16.85M 好相位, 判据 0.6): seed7 0.550 /
  seed42 0.6125 / seed123 0.4875 → **1/3 过门**; 与金档时代同带

## 3. op 战役 (M4 期间的重大事件, 2026-10-15 → 10-18)

M4 "op 不崩" 判据执行期间, 物理世界线先后暴露两个结构缺陷与一个深层
病情; 全部定位、修复、验证:

### 3.1 B10 — camp-freeze 退化 (设计缺陷, 已修)

- 症状: 16.85M→17.35M 抓握率 10.8%→100% (抓握动作=原地冻结), op 0.47→0.28。
- 根因: `occluder_reach_hold: 5.0` 圈内**无界**每步支付 (最高 ~4/步) +
  抓握=冻结 → "到达+永久驻留"最优; 实测静止步收 0.1417 > 移动 0.1308。
  附带: 早退守卫漏查 hold/reach/reveal 三项。
- 修复: `occluder_reach_hold_max_steps: 15` 有界窗口; 守卫补全七项;
  `test_occluder_hold_cap.py` 3/3。行为恢复: 抓握 100→2.1%, 移动 0→96.9%。

### 3.2 A13 — teacher 退火泄漏 (静默断链, 已修)

- 症状: teach loss 2.16 常数贯穿全时代 (≈chance)。
- 根因: tgate 退火到 0 后门控块停止运行, `env.occluder_teacher_force`
  停在最后赋值 (0.05) → 教师恒以 ~5% 覆盖动作。
- 修复: else 分支显式置 0.0; 台账规则: "开关变量的关闭必须显式赋值"。

### 3.3 锁相 (输入坍缩 + 平坦盆地) 与 LR 脉冲破局 (已修)

- 症状: 20.75M 起单方向锁死 (move_SE 95%→SW 84%), op 锁 0.131 逾 1.2M 步。
- 审计 (多轮, 全部有数据): LR 常数无调度; 全参数头活跃; advantage std
  31-61 健康; 每更新 kl ~0.004 极小; slot 指标全时代恒定 (含金档, 非病理);
  输入归因 — 网络对噪声敏感 (8 动作) 但对真实游戏输入恒定 (锁死档恒 [5],
  金档响应 [1,7] → 游玩分布上的输入坍缩)。教师示范 (0.5×2 段) 与
  entropy/orient 强化均推不动。
- **修复: LR 脉冲 (3e-4→1e-3, 有界 2 段)**: kl 升至 0.009-0.058, 策略熵
  2.13→2.38, 锁相瓦解。回落 3e-4 后**保持并凝结**:
  - op: 23.6-23.95M 全段 **0.69-0.83** (跨种子: 23.85M seed42 0.811 /
    seed7 0.796)
  - 事件/局: 2100-2300 (金档 1699); no_move 9.5% (金档 15%)
  - 方向: 混合 (最大份额 26%, 单方向锁死消失)
  - 严格门控 advisory: **PASS** (mean5 0.784 / min3 0.796) — 战役首次。
- **全指标超越金档 12.05M (0.694)**。

## 4. 诚实负结果与教训

1. M1 分类增益负结果 (如实归档); 层级价值只在 M2 使用端兑现。
2. movable 通道休眠 (策略无搬运经历) — 通道能力待未来环境激活。
3. num_sense 1/3 过门 (边界表; 与时代带一致)。

   (行为锁死) — 环境单调性本身是发育病理来源; 此为 Stage 23 (退出隧道)
   的直接动机。
5. 三波干预 (B 探索 / C2 转向激励×4 / C3 教师示范) 全部按止损协议
   回落; 破局来自动力学审计后的 LR 脉冲 — **诊断先于干预**再次被验证。
