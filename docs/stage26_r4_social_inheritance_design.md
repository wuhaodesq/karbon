# Stage 26 R4 Design — 社会继承实验 (Social Inheritance)

> Status: **design draft** (2026-11-10), 预注册。前置: R1/R2 完成, R3-b
> 槽位接口上线 (下游验证中)。本实验回答: **智能体能否从"他人的验证
> 经验"(文本) 学习，而不是只能从自己的经历学习？**

---

## 0. 为什么这是"社会继承"而不是"自己读书"

R2 的文本断言由**同一个世界的程序化生成器**产生。若只用智能体自己
经历过的场景生成文本，那只是"用文字巩固自己的经验"——不是社会继承。
真正的社会继承 = **学习自己没经历过的他人的经验**：

- 生成器在**独立环境/独立种子**的回合里采样场景，产出经验证的事实文本
  （"other agents' experience"）
- 智能体通过 R2 摄入这些事实（它自己的观察里没有这些场景）
- 度量：**它能否回忆/使用自己从未经历的事实**（held-out recall）

这对北极星的意义: 人类知识量的指数增长来自语言传递他人经验。

## 1. 协议 (预注册)

```
臂 A (阅读/继承): 事实库启用 R4 语料 (独立环境的已验证事实, 每段 N=2000 条)
臂 B (自经验):  事实库仅来自本环境 (R2 现状) 或关闭继承语料
两臂: 同起始 ckpt、同种子、同时长 (2 段)

度量 (每臂每段):
  1. held-out 事实回忆: 从"独立语料"抽 200 条未强化过的事实,
     用 R3 消费端 (槽位/数感头/概念探针) 回答 (存在性/计数/遮挡)
  2. 语料覆盖: 继承语料的场景分布 vs 本环境分布的距离
  3. op 不变量 + 任务回报
判据: 臂 A 的 held-out 回忆 ≥ 臂 B + 0.15, 且 ≥0.5 绝对值;
      op ≥0.25 带 (输入通道纪律)
失败: 差距 <0.05 → 诚实负结果 (本架构无社会继承优势), 归档
```

**语料生成器**: `scripts/eval/gen_inherit_corpus.py` (独立种子环境 → 场景 →
R1 验证器过滤 → 事实文本, 有界 ≤2000 条/段; 与 R2 的断言生成器共用词表)。

## 2. 依赖与诚实边界

- **依赖 R3 消费端**: "回忆"必须有可测的消费路径 (目前是槽位+数感头;
  若 R3 下游验证失败, R4 顺延 — 设计先行不启动)
- **不声称语言理解**: 事实是模板文本 (词表解析), 不是自由文本;
  自由文本阅读是 B 档 (语言规模化), 不在本实验范围
- **不偷看**: 两臂的世界交互完全一致 (同 env/课程), 唯一差异 = 语料来源;
  不得让继承语料包含本环境当前场景 (防泄漏)

## 3. 硬件账

- 语料生成: 独立 env 回合, CPU/GPU 少量 (~5 min/2000 条)
- 事实库: +2000 条/段 (远低于容量)
- 训练: 无新增 (R2 摄入已在线); 评估: held-out 回忆测试 (~10 min/臂)
- 结论: **零新增硬件**, 复用现有基础设施

## 4. 里程碑与时间线

| M | 交付 | 判据 | 估时 |
|---|---|---|---|
| R4a | 语料生成器 + 泄漏检查 | 语料 2000 条, 与本环境场景重叠 <1% | 1 天 |
| R4b | 双臂运行 (2 段) + held-out 回忆电池 | 臂 A ≥ 臂 B + 0.15 且 ≥0.5; op 稳 | 2 天 |
| R4c | 报告 | 诚实结论 (含失败归档) | 0.5 天 |

## 5. 与北极星

社会继承 = 语言门的最终意义。若成立, 智能体首次实现"从他人的验证
经验中学习"——这是从"自我发育"到"文化继承"的台阶; 若不成立, 得到
设计级结论: 本架构的社会继承需要什么 (例如更丰富的语料/更强的
消费端), 而不是继续调参。
