# Stage 25 Design — 语言进入行为回路 (Language in the Action Loop, 15y+)

> Status: **design draft** (2026-11-03). 承 Stage 23 语言接口 (L-out 1.0/0.0,
> L-in 0.94/1.0-memory) 与 Stage 24 自主目标负结果 (M2b 回退, 双稳态调查结案)。
> 主题: 把"已验证的指令解析"变成**训练信号**, 让语言从接口层进入行为回路。
> 纪律: M2b 的教训直接写进设计 —— 条件化输入必须有【专属奖励信号】,
> 且接入段起即监控任务关键不变量 (op), 单段回退预注册。

---

## 0. Carried context

| 来源 | 内容 |
|---|---|
| Stage 23 | L-out 接地语音门 1.0/0.0; L-in 指代 1.0 / 匹配 0.94 / 记忆 1.0 (battery) |
| Stage 24 | M2b 失败: 无专属信号的条件化输入 → 学成任务偏置 → op 坍塌; 回退后恢复 |

## 1. 目标 (operationalized)

1. **指令条件化行为**: 环境侧采样指令 ("reach the red box" 等模板),
   智能体按指令走向**被指名的物体** — 与随机指令对照臂比较.
2. **专属信号**: 到达指令目标 = 一次性奖金 (每窗口 ≤1 次, 有界窗口),
   这是该输入通道唯一的学习信号 (M2b 教训).
3. **不倒退**: op ≥0.50 带; 0 NaN; 双稳态低模不因新通道恶化.

## 2. 机制 (bounded, 复用现有管道)

```
指令窗口 (every 400 步, bounded):
  采样指令 (kind, color) --词表--> 语义向量 (kind one-hot 6 + color one-hot 7
  + 目标相对位置 dx,dy) = 15 维, 复用 goal 21 维管道 -> 零初始化投影入 actor
  解析层: 已验证的模板词表 (M3b), 本轮不做原始文本编码 (M-L2 再做)
  指代解析: 用环境物体列表匹配 (kind, color); 无匹配 -> 重采样/跳过 (记录)
达成判定 (环境侧, 不自报):
  到达半径 0.8m (与遮挡 reach 同口径) -> 一次性奖金 (默认 +3.0, 每窗口 ≤1 次)
对照臂 (同运行):
  随机指令 (均匀采样, 无奖金) — 仅观测, 不进 actor; "指令匹配率" 判据:
  chosen 到达率 ≥ control +10pp
```

**为什么这个设计大概率不会重演 M2b**:
- 目标**可执行**: 到达半径内完成, 窗口 400 步 ≈ 可达 (世界 ~4m).
- 输入有**专属信号**: 到达奖金是该通道唯一样本来源.
- 输入语义与**已学技能对齐**: 遮挡 reach 塑形证明策略已会追目标 (op 0.65-0.75 带).

## 3. 里程碑 (预注册)

| M | 交付 | 判据 | 估时 |
|---|---|---|---|
| **M-L1** | `instruction_channel.py` (窗口采样/指代解析/到达判定/对照臂) + 训练接线 (复用 goal 向量管道) | 单测全绿; 接入段 0 回归 (op ≥0.50, 0 NaN); 2 段后指令到达率 ≥ control **+10pp** | 2 天 |
| **M-L2** | 原始文本编码 (冻结 CLIP 文本分支或结构化→文本一致性) | 语义向量与文本编码的指代一致性 ≥0.9; 指令到达率保持 | 1-2 天 |
| **M-L3** | 复合指令 ("the red box *behind the wall*", 含遮挡/记忆指代) | 记忆指代到达率 ≥ control +10pp; op 不倒退 | 2 天 |
| **M-L4** | 长程浸泡 + 与 Stage 23 判据同口径复验 | 0 崩坏; 广度不回退 (相位口径) | 2-3 天 |
| **Exit** | 报告 + tag `v0.25.0-stage25` | M-L1..L4 全绿或诚实缺口归档 | — |

## 4. 风险 / 诚实守卫

- **输入通道纪律 (M2b 教训)**: 接入段起每段记录 op; **单段 op <0.30 或
  连续 2 段 <0.45 → 立即回退** (config 关闭); 回退不调参重试.
- **指令≠能力**: 到达率是行为指标; 不声明"语言理解"升级 — 词汇/句法/
  对话仍不在范围 (参见 Stage 23 语言计划 §6).
- **解析层披露**: M-L1 的"语言"是结构化语义向量 (词表解析), 不是原始
  文本编码; 文本编码留 M-L2, 且只允许冻结编码器 (无决策权).
- **对照臂**: 随机指令臂无奖金, 判据用同运行对照; 2 段后若分离 <+5pp
  → 诚实负结果归档.
- **双稳态**: 低模段不计入 M-L1 判定 (相位口径), 但低模占段率恶化
  >50% 即停.

## 5. 实施顺序

1. `src/models/instruction_channel.py` + 词表 (复用 M3b) + 单测.
2. train.py 接线: 窗口采样/指代解析/到达奖金/对照臂/遥测 `[instr]`;
   复用 goal 向量管道 (goal_session 关闭, 由 instruction channel 填充).
3. 部署观察 2 段: `instruction_channel_enabled: true`.
4. M-L2: 文本编码一致性.

## 附: 与北极星的关系

语言是四道硬门之一。本阶段把"能解析的指令"变成"能塑造行为的指令",
是从 9 岁"能听懂"向"用语言指导行动"的发育台阶; 结构化->文本 (M-L2)
与复合/记忆指令 (M-L3) 依次逼近真实语言使用。

## 6. 仪器修正 v2 (2026-11-04, 判定前声明)

- **发现**: 到达率主指标撞天花板 —— 0.8 m 半径在 400 步窗口内双臂
  ~95% 环境性命中 (chosen 95.5% vs control 94.1%, +1.4pp), 无分辨率。
  这是仪器缺陷 (M2a/B16 家族), 不是机制失败; 通道本身安全
  (夜间 4 段 op 0.718/0.730/0.782, 无坍塌)。
- **修正 (判定前声明, 非调参)**:
  1. 主指标 = **到达时间** (窗口内步数, chosen vs control, 配对比较);
  2. 记录窗口起点距离 (d0) 作协变量;
  3. 到达半径 0.8 → **0.5 m** (降低环境性命中);
  4. 到达率保留为辅助指标。
- **更新后的 M-L1 判据**: 两段后 t_chosen 显著快于 t_control
  (均值或配对中位数差 ≥ **50 步 / 20%**), 且 op ≥0.50 带;
  若差 <10% → 诚实负结果归档。
- 世界放大 (M2-p3) 另行立项: 物体分散 + 布局 8-12m, 走 M2-p2 剧本
  (冒烟 + 2 段迁移审计 + 布局口径 + 回退守卫); 完成后再复测指令通道。

## 7. M2-p3 世界放大 (预注册, 2026-11-04)

- **变更**: 物体 spawn 半程 1.8 → **3.0 m** (6×6 m arena; 房间仍为**名义**,
  不做物理隔断/门 —— 物理房间化是后续里程碑, 单独立项). 新增 env 参数
  `object_spawn_half`; 训练三条 builder 路径 + 全套评估/诊断脚本同步
  (A15/B12 教训: 所有 builder 路径必须同参).
- **判据**:
  (a) 冒烟: obs(128,128,3)/proprio(27)/动作(12) 形状不变;
      物体对距离中位数 ≥ 2.5 m;
  (b) 2 段审计: 0 NaN; op diag 按**布局口径**解读 (事件可能减少 —— 是布局
      不是策略问题); task reward 不崩 (>50% 跌幅 → 调查); 行为解剖无新锁死;
  (c) 指令通道: d0 中位数 ≥2.5m, t_chosen/t_control 差异可测.
- **回退**: 连续 2 段 op <0.30 或 task return 跌 >50% →
  `object_spawn_half: 1.8` 恢复 (config 切换, 无需改码).
- **动机**: 小世界使"到达/指令"全部环境性命中 (M-L1 仪器天花板);
  空间尺度是发育维度 (TIMELINE 未验证实验: 场景复杂度/长程技能).

**设计迭代 (冒烟驱动, 部署前)**: 3.0 (6x6m) 冒烟: 对距中位 1.91m < 2.5
判据 → 未采用; 4.0 (8x8m): 中位 **2.547m**, max 6.06m, 契约不变
(obs 128x128x3 / proprio 27 / 动作 12) → **采用 spawn_half=4.0**.
**运维事故记录 (C11 复发)**: 一次窗口脚本用 here-string 生成 →
PowerShell 展开 $LOG/$busy/$(seq) → 脚本静默失败且未重启链,
训练停 ~11 分钟 (手动恢复)。安全路径 = 本地 write 工具写脚本 + sftp。

**边界事故与修复 (2026-11-04 21:40, M2-p3 第 2 段发现)**:
- 症状: [instr] d0 从 1.8m 暴涨到 85-134m (双臂同距), 达成冻结 —
  学习者 (无位置边界的速度控制体) 在大场地里加速漂出竞技场。
- 修复: `_bound_learner()` 钳制 learner x/y 关节到 arena+0.5m 并清零
  越界速度 ("墙"的物理隐喻; obs/proprio 契约不变)。
- 验证 (冒烟): 定向漂移 (持续 +x 400 步) max|x|=4.06 ≤ 4.7 ?;
  随机漫步 1.82m ?。
- 影响: 21:20 之后的 [instr] d0/t 数据作废 (标注); 新段起数据有效。
  该修复也是(op/任务奖励)行为变化, 纳入 M2-p3 迁移审计。

## 8. M-L1b 仪器 v3: 配对优先 (2026-11-05, 判定前声明)

- **基线诊断**: 控制臂到达时间 min 0 / median 121 / max 399 (IQR 28-282),
  起点距离 d0 0.4-6.8m —— 到达时间被 d0 主导; "跑赢中位数"会奖励
  "目标恰好近"的运气, 不是跟随指令。
- **仪器 v3**: 每窗口同时测两臂 (同一时刻/同一位置, d0 由构造控制),
  指标 = 配对胜率 P(t_chosen < t_control); 奖金改为配对优先规则
  (chosen 比随机目标先到才付, 每窗口 ≤1 次)。
- **判据 (更新)**: 两段后配对胜率 ≥ 0.60 (机会线 0.50) 且 op ≥0.50;
  <0.55 → 诚实负结果。`proj_norm` 遥测判断语义向量是否被使用。
- **动机**: 配对设计把"是否跟随指令"从"环境性到达率"里剥离出来,
  这是能教会策略的唯一干净信号 (M2a 的教训: 无区分奖励 = 无学习)。

### M-L1c: 对照臂修复 (2026-11-05 14:35, 日志发现)

- **症状**: 配对胜率 0.03-0.08 (机会线 0.50) —— 统计不可能, 是仪器 bug。
- **根因**: 对照臂从 4 kinds × 7 colors = 28 组合均匀采样, 大多数组合
  在场景中**不存在** → 回退到 chosen 的同一物体 → 两臂追踪同一目标,
  同时到达成平局 (~85% 的窗口) → 胜率被稀释到 ~0.08。
- **修复**: 对照臂改为**随机现存的其他物体** (id ≠ chosen, 文本用其
  真实 kind/color); 配对胜率从此有意义 (机会线 0.50)。
- **影响**: 修复前 (含修复前 [instr] win_rate 与配对奖金) 的数据作废;
  修复后 ~1 小时 deque 刷新后开始有效计数。
