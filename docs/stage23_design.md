## 1. Stage goal (per TIMELINE)

**开放世界永续**: 自主目标设定 (扩展世界接入 + 内驱→自主目标 + 无限稳定),
15y+; 内在动机替代课程驱动, 100 万步+ 稳定。

**验证口径 (operationalized)**:
1. **退出隧道**: 多目标环境并行 (非 op 奖励通道恢复), op 保持回归监控级
   (≥0.3, 无深坍缩)。
2. **内驱→课程**: 任务选择权重由内在信号 (RND/覆盖/好奇/假设探针) 驱动,
   外部课程权重在 ~200-500k 步内退坡。
3. **广度恢复**: 里程碑套件 (OP/ToM/means/physics/num/systematic) 在好相位
   与 2-3 个种子上复验, 相对 Stage 20 金档时代**不回退** (OP≥0.6,
   ToM≥0.5, 物理/系统≥0.7)。
4. **永续稳定**: ≥1M 步连续无崩坏 (value 爆/NaN 0 次; 行为无新锁死)。

## 3. Design sketch (bounded)

```
环境层 (M1): focus_op_only=false; 非 op 奖励通道恢复 + 权重再平衡
  └─ 5 个 3D 任务 + 抓取/tool/key_door 目标并行 (dev_age 0.5 已有)
  └─ op 回归监控: 每 50k 全局 diag; 连续 2 段 <0.3 → 临时回 op-focus
课程层 (M2): 任务采样权重 ∝ 内驱缺口 (novelty deficit per task, 有界)
  └─ 外部 curriculum 权重 200-500k 步内线性退坡
  └─ 遥测: 任务分布 / 内驱奖励占比 / 各任务回报
验证层 (M3): 里程碑套件 ×2-3 好相位档 ×2 种子; 对照金档时代
稳定性 (M4): 1M 步连续浸泡 (接力链), 崩坏监视 + 广度末测
```

## 5. Risks / honesty guards

- **op 回潮 (农场再发)**: 任何"每步持续收益"必须设有界窗口 (台账 B10 规则);
  切换后头 2 段做解剖对照 (抓握/方向/事件/静止).
- **奖励再引入的旧病**: 露营/单规则捕获历史; 恢复的非 op 通道逐个开
  (小步), 每开一个看 2 个段的解剖.
- **课程解锁口径**: rw_rate 阈值校正必须记录校准依据 (不得偷偷放宽).
- **数量化陷阱**: 广度判据含行为侧 (事件/参与度), 不只分数.
- **语言**: 仅在 M3 评估; 接入与否按判据 (不带预设结论).
- **硬件**: 训练/评测按预设参数; 交付上限 home_64g 不变.

## 7. M2 第二阶段方案: 世界扩展 (World Expansion, 代码就绪 2026-10-22)

**目标**: 首段 M2 (内驱→任务选择) 稳定后, 把训练世界从单一房间过渡到
`ExtendedThreeDWorld` (4 房间 + 兄弟姐妹 + 季节 + 门径导航), 检验
"丰富环境里广度是否继续生长" (设计 M2 "世界变体接入" 项)。

**现状发现 (2026-10-21)**:
- `ExtendedThreeDWorld` 已存在; train.py 已有 env_id 分支, **但只传了 5 个
  参数** (num_objects/seed/max_episode_steps/render_size/developmental_age) —
  occluder/奖励/槽/教师等全丢 → proprio_dim=18 (模型 27) → resume 时
  `strict=False` 会静默随机化 proprio 支路 (危险, 必须先修)。

**实施步骤 (小步)**:
1. `ExtendedThreeDWorld.__init__` 接受 `**kwargs` 并转发给
   `ThreeDWorld.__init__` (occluder/奖励/focus/clamp/槽/教师全套)。
2. train.py Extended 分支改为传与 ThreeDWorld 相同的 `_kw` (+ num_siblings/
   season_cycle_steps)。
3. M2-p2 试验配置: `env.id: ExtendedThreeDWorld`; render_size **128** (模型
   兼容), occluder_obs_slots **3** (proprio=27), num_occluders 4,
   num_objects 16-24 (起始小), num_siblings 1-2, developmental_age 0.5,
   max_episode_steps 300-500, focus_op_only false + 完整阶梯 (B11 已修)。
4. 冒烟 (不上训练): obs_shape==(128,128,3), proprio_dim==27, action_n==12;
   随机步 N=200 无崩溃、奖励非零。
5. 有界试验 2 段 + 审计: 解剖 (B10 模式), op diag (diag 环境为 ThreeDWorld —
   天然成为"旧世界回归/迁移检查"), [concept] 实例增长, 季节轮换遥测。
6. 风险: 4 房间布局下遮挡事件稀疏 (op 读数低可能纯因布局); siblings 路径
   未测 (冒烟覆盖); 500 物体库过重 (num_objects 封顶起步)。

**判据**: 冒烟全绿; 2 段内无 NaN/无锁死; op 回归监控 ≥0.3 (诊断口径可解释);
新旧世界行为差异如实记录; 通过则保留扩展世界为 M2/M3 常驻环境。


## 8. 决议: 平衡相位接受 + 相位口径规则 (2026-10-28)

- 三层修复 (B10 奖励 / babble 驱动 / 动量身体) 后, op 在多目标平衡下
  稳定于 0.55 带。**接受为监控带** (≥0.50 接受; 连续 2 段 <0.45 调查;
  <0.30 回退), 远高于设计底线 0.3。
- **能力/年龄声明口径**: 一律引用好相位档案并标注相位
  (当前最强证据: 27.1M — OP 0.847, est 9.0y 双种子); 平衡相位快照
  (39.35M — OP 0.56-0.60, 手段 1.0, 物理 0.94, 系统 0.66) 仅作
  结构参考。禁止为追 0.6 旗子调权重 (count-only 陷阱)。
- 自动触发器 (连续 2 段 ≥0.6 → 好相位补测) 保持 24h 在岗。
